# Architecture Decision Records (ADRs) for ANTIGRAVITY

This directory contains Architecture Decision Records (ADRs) for the ANTIGRAVITY project. ADRs are short, focused documents that capture a significant architectural decision, its context, the decision made, and its consequences. They serve as a historical log of important architectural changes and the rationale behind them.
