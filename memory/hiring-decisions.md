## Decision Framework

### Hiring Criteria

| Factor | Weight | Threshold | Measurement |
|--------|--------|-----------|-------------|
| Skill Match | 40% | Must cover primary task | Skill description vs task requirements |
| Token Cost | 20% | < 50K tokens/heartbeat | Token usage per task |
| Maintenance | 20% | Updated within 30 days | Last modification date |
| Track Record | 20% | Success rate > 80% | Historical performance |

### Decision Process

1. **Identify Need**
   - What task needs completion?
   - What skills are required?
   - What's the token budget?

2. **Search Candidates**
   - Check agent-roster.md for available agents
   - Check skills directory for matching skills
   - Evaluate token costs

3. **Evaluate**
   - Score against criteria
   - Compare to alternatives
   - Risk assessment

4. **Decide**
   - Hire (assign agent + skill)
   - Defer (wait for better option)
   - Reject (document reason)

5. **Track**
   - Log decision in this file
   - Update agent-roster.md
   - Monitor performance
