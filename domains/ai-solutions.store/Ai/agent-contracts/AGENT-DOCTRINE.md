# Agent Doctrine — S1 Draft

> **DRAFT ONLY:** This document supersedes older multi-lane, external-memory, retired-runtime, and stale-path instructions. It becomes active only when the judge lane lands the S1 supersession.

## Current Operating Model and any Ai model should do the same regarding a journal it reads on session starts writes to on session end even for JUDGES

The active harnesses are **Hermes**, **OpenClaw**, and **OpenCode**. They are not permanent authorities. Joshua assigns work; the assigned harness performs its bounded scope and reports evidence.

All three work only from `C:\ANTIGRAVITY`, read their own repository journal at session start, and write a concise state entry at session end. Their journals, repository knowledge, Graphy, and optional Obsidian mirroring provide durable context without an external memory dependency.

## Readiness Before Delegation

No harness plans or assigns a subtask until it loads the skills relevant to that task. The preflight rules live in `JOURNAL-PROTOCOL.md`. `i-have-adhd` is a token-saving/action-first output skill, not a diagnosis. The installed capability set includes Superpowers brainstorming, Agent-Reach, browser-use, find-skills, TDD, and systematic debugging.

## Routing and Delivery

Authenticated OmniRoute is the normal cloud model route. Ollama is explicit fail-safe only. Official-platform governance ballots are routed through their designated official bridges and never through OmniRoute.

Only the judge lane pushes, merges, or deletes branches unless Joshua directly authorizes an exception. Every delivery remains **BLOCKED** until the required review and evidence exist.

## Reporting

Every report identifies the files changed, skills used, content-level verification, unresolved blocker, and one next action. Never substitute confidence, a port listener, or HTTP status for evidence. Never expose secrets or private browser credentials.
