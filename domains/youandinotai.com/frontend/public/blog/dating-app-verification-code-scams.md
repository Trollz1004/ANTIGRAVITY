# How to avoid dating app verification code scams and account takeovers

Dating app verification code scams target people who look for real connections online. Scammers create fake accounts to steal phone numbers, personal email addresses, and account credentials. In February 2024, the [Federal Trade Commission report](https://www.ftc.gov/business-guidance/blog/2024/02/love-stinks-when-scammer-involved) stated that romance fraud caused $1.14 billion in reported losses in 2023. Understanding how verification code requests work helps you protect your personal information.

## How the verification code trick works

The scam usually begins with a match who seems friendly and attentive. After a few messages, the person asks for your help with a simple task.

1. The match claims their phone broke and asks if they can send a six-digit code to your phone number.
2. The match claims they need to verify you are a real person on an outside site by sending a code.
3. The match attempts to log into your Google, social media, or bank account and triggers a password reset.
4. The scammer asks you to read the six-digit code back to them right away.
5. Once you share the code, the scammer takes over your account or registers a voice service in your name.

Legitimate members never need you to receive a text code for them. Any request for a temporary code means an account takeover attempt.

## Warning signs in early messages

Scammers rely on urgency and confusion to get your codes before you realize what happened. Look for these warning signs in your conversations.

1. The match asks for your mobile phone number within the first three messages.
2. The person sends a link to an unfamiliar website and asks you to confirm your identity.
3. The match creates a sense of emergency, claiming they will lose access to their profile.
4. The text message with the code says do not share this code with anyone, yet the match asks for it anyway.
5. The conversation suddenly stops as soon as you decline to send the code.

When a match asks for a login code or one-time password, stop messaging immediately. Use block and report tools to flag the account for platform review.

## Steps to take if you shared a code

If you gave a code to a match, act quickly to protect your personal accounts.

1. Change the password on the service that sent the text message.
2. Log out of all active sessions across all devices in your account security settings.
3. Check your email forwarding rules and account recovery phone numbers for unauthorized changes.
4. Contact your mobile phone carrier to set a PIN for account changes and SIM card transfers.
5. File a report with the platform and your local authorities if financial information was compromised.

Fast action limits the damage and prevents scammers from accessing other linked services.
