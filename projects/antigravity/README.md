# ANTIGRAVITY Project

## Overview

The ANTIGRAVITY project operates the YouAndINotAI platform, a social platform for good focused on real-world human connection, meetups, and volunteering opportunities. Our mission extends beyond typical social networking by incorporating a charitable component where revenue supports children's charities through contractual revenue disbursement.

## Key Components

1. **YouAndINotAI Platform** - Main social platform with verification, moderation, and subscription flows
2. **Charitable Giving Program** - Contractual revenue disbursement to qualified children's charities
3. **Volunteering Marketplace** - Facilitating real-world community engagement opportunities
4. **Safety & Moderation Systems** - Advanced content moderation and user protection measures

## Technology Stack

- **Frontend**: React, Next.js, TypeScript
- **Backend**: FastAPI / Python services
- **Commerce**: Square integration
- **Hosting**: Cloudflare Pages and Google Cloud Run
- **Database**: PostgreSQL
- **Operations**: Windows-based multi-node build and support workflow

## Strategic Priorities

1. Platform Development Excellence
2. Sustainable Growth and Monetization
3. Community Trust and Safety Leadership
4. Charitable Impact Maximization
