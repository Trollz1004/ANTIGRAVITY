## docstrings

<module>:
Verification gates for the unattended daily run.

The failure this exists to prevent: a stage exits 0, writes a file nobody looks
at, and the chain ships a 0-byte mp4 -- or a video that plays as thirty seconds
of black with silence. Every gate here probes the artifact that was actually
written and raises on the first thing that is wrong. Nothing downstream is
allowed to assume a stage succeeded because it did not throw.

Each check is recorded (pass or fail) on a GateLog so the packet shows what was
verified, not just what broke.


  GateError:

  GateLog:

      <genexpr>:
ok

  probe:
Raw ffprobe JSON for a media file. Raises GateError if ffprobe rejects it.

    <genexpr>:

  video_playable:
Container parses, has both streams, right shape, sane length.

  audio_not_silent:
A muxed-but-silent track is the quiet failure mode. Measure it.

  frames_not_blank:
Sample frames and reject flat ones. A black or single-colour render has
near-zero luma spread; a real designed frame has type on a gradient.
