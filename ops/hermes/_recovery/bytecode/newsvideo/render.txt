## docstrings

<module>:
Assemble a day folder into a finished vertical mp4.

Per segment: one designed frame + one real voiceover clip. The frame is held for
exactly the clip's measured duration plus a tail, under a slow push (zoompan) so the
result reads as produced video rather than a slideshow. Segments are concatenated
without re-encoding, then probed.

Every duration in the manifest comes from ffprobe on the file that was actually
written -- nothing is estimated.

  synth_all:
Generate every voice clip for a day, honouring the requested backend.

  render_day:
Render one day folder to mp4 under out_root/<day>/. Returns the manifest.

Deliverables land outside content/yesterday-news/ on purpose: a second pipeline
writes <day>.mp4 / <day>-thumb.png / upload.json into those day folders, and
rendering there would silently overwrite it.
