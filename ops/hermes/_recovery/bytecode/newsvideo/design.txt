## docstrings

<module>:
The channel's visual system: one layout, one type treatment, applied to every frame.

This is the template layer for the batch -- imagery varies per story, the grid and the
type treatment never do, so the videos read as one channel. Frames are drawn at a
supersample factor and downscaled by ffmpeg, which keeps type crisp under the slow
zoom applied at assembly.

No stock library ships with the repo and no image provider is reachable, so the
backgrounds are deterministic generated gradients keyed to the story index -- the
placeholder path the faceless-news skill spec calls for, not a stand-in for a
missing asset.


  Frame:
Frame

  _hue_for:
Stable hue per story so a day's five backgrounds differ but never drift off-brand.

  _fit:
Largest size in [lo, hi] whose wrapped block fits the box.

  render_thumbnail:
16:9 thumbnail on the same system -- same wordmark, chip and type treatment.
