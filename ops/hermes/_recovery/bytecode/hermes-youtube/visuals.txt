## docstrings

<module>:
One 1080x1920 background per story.

Attempt order:
  1. OmniRoute POST /images/generations (issue TRO-2 step 3)
  2. Deterministic locally-rendered background + caption (SKILL.md step 4,
     which prescribes this exactly because the repo has no stock library)

Both paths produce real PNGs. The manifest records which path made each file so
the evidence packet can report the visual source honestly.


  omniroute_image:
Generate a background. Returns (PIL image or None, note).

The untouched provider bytes are kept at raw_path as evidence that the
image really came from the gateway.

  subject_phrase:
Content words from a headline, for prompting.

Feeding the headline in verbatim makes the image model render it as
(garbled) on-image typography, so the prompt gets a keyword phrase and the
caption layer carries the actual words.

  prepare_generated:
Blur and dim a generated image into a usable backdrop.

Image models leak text even when told not to, so the background is blurred
hard: residual glyphs become texture and the caption stays the only
readable thing in frame.

  cover_crop:
Scale to cover then centre-crop, so a square generation fills 9:16.

  gradient_background:
Deterministic gradient used when no image provider answers. Same input
always yields the same image, so a re-run reproduces the video exactly.
Returns (image, kicker_colour).

  add_caption:
Composite the kicker + headline card over any background.

A generated image has unpredictable local contrast, so the text always sits
on a semi-opaque black card and the frame gets a vignette. That keeps the
headline readable whichever background path produced the image.
