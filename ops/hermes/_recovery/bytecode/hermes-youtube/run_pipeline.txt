## docstrings

<module>:
Run the whole faceless-news pipeline for one day folder.

    python run_pipeline.py                 # newest eligible day folder
    python run_pipeline.py 20260901        # a specific day folder

Stages: clean -> narrate -> visuals -> assemble -> packet. Each stage is the
same script that can be run on its own, so a failure can be retried in place
without redoing the stages before it.

Nothing here publishes. Upload stays manual until Joshua records approval.


  pick_day:
Newest dated folder. Per SKILL.md, if that is today, use the one before.
