## docstrings

<module>:
Generate narration audio per segment.

Order of attempts, highest quality first:
  1. OmniRoute POST /audio/speech (spec path, tts-1-hd)
  2. OmniRoute /audio/speech on any other speech provider that has credentials
  3. Windows SAPI (System.Speech) -- offline, real synthesis, no SaaS, no spend

Every segment records which engine produced it so the evidence packet can mark
VERIFIED/UNVERIFIED honestly. Nothing here ever writes a silent or fake file.


  omniroute_speech:
Return (True, note) on success, (False, note) if no provider is usable.

  sapi_speech:
Windows SAPI to WAV. Real offline synthesis.
