# UX Designer - ANTIGRAVITY Project

## Role Overview

The UX Designer is responsible for creating intuitive, engaging, and accessible user experiences across all ANTIGRAVITY platforms. This role focuses on understanding user needs, designing interfaces that facilitate meaningful connections, and ensuring the platform is both usable and aligned with the mission of social good.

## Key Responsibilities

### User Research & Analysis

- Conduct user research to understand needs, behaviors, and pain points
- Analyze user feedback and behavioral data to identify improvement opportunities
- Create user personas and journey maps for different user types
- Perform usability testing and accessibility audits

### Interface Design

- Design wireframes, prototypes, and high-fidelity mockups for all platform features
- Create design systems and component libraries for consistency
- Ensure responsive design across all device types and screen sizes
- Design accessible interfaces that comply with WCAG standards

### User Experience Strategy

- Develop and maintain UX strategy aligned with business goals
- Define user flows and information architecture
- Create interaction design patterns and guidelines
- Optimize user onboarding and retention experiences

### Collaboration & Communication

- Work closely with developers to ensure design feasibility and quality implementation
- Collaborate with product managers to define feature requirements
- Communicate design decisions and rationale to stakeholders
- Coordinate with AI agents (particularly Designer and Gemini) for visual assets and UI elements

### Continuous Improvement

- Monitor user behavior metrics and identify optimization opportunities
- Stay current with UX trends and best practices
- Iterate on designs based on user feedback and testing results
- Document design processes and maintain design assets

## Key Platforms & Products

- YouAndINotAI.com (primary dating/social platform)
- OnlineRecycle.org (community marketplace)
- ai-solutions.store (AI solutions marketplace)
- Administrative dashboards and internal tools
- Mobile applications (planned for Google Play and iOS)

## Design Tools & Technologies

- Figma or comparable design tools
- Prototyping tools for user testing
- Analytics platforms for user behavior analysis
- Collaboration tools for design system management
- Understanding of React and modern frontend frameworks

## Special Considerations for ANTIGRAVITY

- Design with the charitable mission in mind, emphasizing community impact features
- Balance monetization elements (Bot-Shield, Founding Memberships) with non-intrusive UX
- Consider safety and privacy implications in all design decisions
- Ensure inclusive design that accommodates diverse user groups
- Focus on facilitating real-world connections and positive social interactions

- Scribe (Content) - Content creation and copywriting
- Motion (Codex + Remotion) - Motion graphics and video elements
- Growth (Atlas + Scribe) - Engagement and acquisition optimization
