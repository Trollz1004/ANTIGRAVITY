# Find Skills

1. Read `.agents/skills/self-improving-system/skills.md` before task work.
2. Match the request to the smallest useful set of existing skills.
3. Read each selected `SKILL.md` completely before acting.
4. Search `.agents/skills/` by name and description when the index has no obvious match.
5. Load skill bodies lazily; access to all skills does not mean preloading all skills.
6. State which skills are being used when the runtime supports user-visible updates.
7. If no existing skill fits, invoke `create-skills`.

Skills guide work. They never create authority over Joshua or another AI platform.
