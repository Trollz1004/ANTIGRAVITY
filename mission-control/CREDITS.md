# OpenClaw - Credits & Attribution

## 🏆 Design & Development

**OpenClaw** was designed and built by **[Manus](https://manus.im/)** — an AI workspace platform for autonomous teams.

### Manus Contributions

OpenClaw leverages Manus's core infrastructure and capabilities:

- **AI Workspace Platform** - Foundation for multi-provider LLM integration
- **OAuth Authentication** - Secure user authentication and session management
- **LLM APIs** - Access to multiple language models through unified interface
- **Image Generation** - Built-in image generation capabilities
- **Data Management** - Secure database and storage infrastructure
- **Notification System** - Owner alerts and real-time updates
- **API Gateway** - Reliable API routing and rate limiting
- **Deployment Infrastructure** - Cloud hosting and auto-scaling

### Manus Team

The Manus team designed and architected OpenClaw to demonstrate the power of autonomous AI teams working together through a unified workspace.

## 🤝 Open Source & Community

### Paperclip

**[Paperclip](https://paperclip.ing/)** - Open-source business OS for autonomous AI companies

OpenClaw integrates with Paperclip to enable:
- Autonomous team coordination
- Task delegation between agents
- Budget tracking and cost control
- Org chart visualization
- Company goal alignment

**Credit:** Paperclip team for creating an open-source foundation for autonomous business operations.

### Ollama

**[Ollama](https://ollama.ai/)** - Local and cloud LLM infrastructure

OpenClaw supports both:
- **Ollama Local** - Running models locally without cloud dependency
- **Ollama Cloud** - Hosted models for scalable production use

**Credit:** Ollama team for making LLMs accessible to everyone.

### OpenRouter

**[OpenRouter](https://openrouter.ai/)** - Model aggregation platform

OpenClaw integrates OpenRouter to provide:
- Access to 100+ models from different providers
- Unified pricing and billing
- Automatic failover between providers
- Cost optimization across models

**Credit:** OpenRouter team for simplifying multi-model integration.
