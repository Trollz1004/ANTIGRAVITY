## What Worked

- Portable OPUS brain on Kraken (I:) — survives node crashes, hot-swappable
- ENIGMA automation structure — modular Python, works across platforms
- Twitter post queue — 26 ready-to-post items with varied angles
- Meta compliance doc from Manus — specific tags and headline recommendations are solid
- Reddit karma-building plan — conservative 5/day avoids shadow bans

## What Failed

- Multiple duplicate automation/ subdirectories on Kraken (cleaned up)
- Command-center copied to wrong location initially — corrected to I:/OPUS/automation/
- E: drive ghosted (FAT32 Xbox USB showed as 0 capacity) — I: is Kraken confirmed

## What to Avoid

- NEVER use charity/donate language — §496.405 violation
- NEVER post Reddit links before karma is built
- NEVER push to remote repos without explicit ask
- NEVER commit secrets — .env only
- Twitter posts: no absolute claims ("100% real people" unless provable)
- Meta ads: avoid audience-diagnosing hooks ("Tired of fake profiles?")
- Pinterest: must use images, hearts/love preferred, 2:3 ratio

## Posting Rules Learned

- Pinterest: 8-11pm optimal, must heart/repin other content
- Reddit: 2-3 min between comments, no links first, real-person voice
- Twitter: images boost engagement, varied angles, no spam feel
- Meta: clean lifestyle visuals, no bedroom/intimacy scenes
- TikTok/YouTube BLOCKED — no video content from OPUS right now
