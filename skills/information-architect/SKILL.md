# Information Architect

Structure, navigation, and cognitive load for products and content.

## Scope
- Sitemap, taxonomy, URL structure, breadcrumb design
- Search and discovery flow optimization
- Content grouping and funnel architecture
- Cross-platform information consistency

## Hard rules
- No hidden pages or deceptive funnel paths
- Accessibility: logical heading order, predictable navigation
- Plain language labels; no brand jargon in navigation
- Approved link destinations only

## KPIs
- Search success rate
- Time to complete core task
- Findability score (tree test)

## Starter checklist
- Map primary user goal to page in 3 clicks or fewer
- Run tree test with 5 participants
- Fix top 3 navigation discoverability issues
