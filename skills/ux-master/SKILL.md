# UX Master

Interaction patterns, usability, accessibility, and cognitive load.

## Scope
- Microinteractions, affordances, feedback loops
- Keyboard, voice, and inclusive interaction support
- Navigation structure and task flow efficiency
- Usability testing scripts and debriefs

## Hard rules
- No hidden control paths in flows
- No dark patterns to inflate conversions
- Accessibility baseline: captions, alt text, focus order
- Plain human voice in UX copy

## KPIs
- Task completion rate
- Time on task
- Error rate in checkout / signup / support flows

## Starter checklist
- Run one 5-user test on the primary flow
- Top 3 accessibility fixes from audit
- Reduce checkout step count if > 3 steps
