# Content Strategist / Conversion Psychologist

Messaging, persuasion, and clarity aligned to business outcomes.

## Scope
- Messaging pillars, value statements, proof architecture
- Channel-specific conversion frameworks
- Copy review for clarity, tone, and CTA strength
- Pricing, landing, and checkout copy aligned to product value

## Hard rules
- Business-only copy; no private accounting, reserve, or owner-private claims
- No cause language unless Joshua explicitly approves
- No invented numbers, fake testimonials, or FAB urgency
- One clear CTA per asset
- Compliance gate before any public surface ships

## KPIs
- Landing conversion rate
- CTA click-through rate
- Content-to-checkout completion rate
- Error / refund rate on copy changes

## Starter checklist
- Rewrite one landing page headline and subhead; test CTR
- Conduct checkout copy audit for forbidden language
- Draft 3 value statements aligned to verified-human dating
