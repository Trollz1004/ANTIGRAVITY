# Designer

Visual systems for product and marketing surfaces.

## Scope
- Layout, typography, color, visual hierarchy
- Mobile-first composition and contrast
- Design-system components, consistent patterns
- Thumbnails, single images, carousels, video overlays

## Hard rules
- 4.5:1 minimum text contrast on images
- No cause/mission/donation language in customer-facing assets
- No cocky tone, no flex, no bot-slop patterns
- One CTA per asset; approved links only

## KPIs
- Task completion rate in primary user flow
- Time on task reduction
- SUS / usability score from tests

## Starter checklist
- Component library for core pages
- One 5-user usability test on primary flow
- Fix top 3 accessibility issues from audit
