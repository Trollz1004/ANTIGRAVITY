════════════════════════════════════════════════════════════════════════════════════
                          HOW IT WORKS
════════════════════════════════════════════════════════════════════════════════════

Request Flow:
─────────────
1. User asks question via youandinotai.com
2. Bot receives query at /api/support/ask
3. Bot searches FAQ data (12 Q&A pairs)
   ✅ Found → return FAQ answer
4. No FAQ match → query Ollama on Sabretooth (192.168.0.8:11434)
   ✅ Ollama responds → return LLM answer
5. Ollama fails → fallback to Gemini 2.0 Flash (if API key configured)
   ✅ Gemini responds → return answer
6. All responses fail → escalate to human support (support@youandinotai.com)
7. All interactions logged to SQLite database (state/support.db)

Response Example:
─────────────────
{
  "ticket_id": 1,
  "query": "How much does it cost?",
  "response": "$1 verification fee + $14.99/month for founding members...",
  "llm_used": "faq",
  "escalated": false,
  "timestamp": "2026-04-02T15:30:45"
}
