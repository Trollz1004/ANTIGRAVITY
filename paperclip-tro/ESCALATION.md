# ESCALATION — Red Issues Die Within The Hour (MANDATORY)

Joshua's standing order: "I never want to see red issues more than an hour without
resolution. If blocked, you don't wait for me — you send it to the CEO. He fixes it
or deletes it."

## The Clock

| T+ | What happens |
|---|---|
| 0 min | Agent hits a blocker. Marks issue RED on the board with: what's blocked, what was tried (≥2 attempts), what's needed. |
| ≤10 min | Agent escalates to CEO (board assignment + note). Agent moves to next task — never idles on a blocker. |
| ≤60 min | CEO resolves by ONE of: **FIX** (unblock it — reroute provider, supply missing pointer, reassign, split the task) or **DELETE** (issue is stale/wrong/unneeded — kill it and log one line why). |
| >60 min | SLA breach. CEO logs breach in own STATE.md `## Improve` and fixes the systemic cause, not just the issue. |

## What Reaches Joshua (ONLY these)

- Doctrine, payments/processor, founder-authority, or legal-exposure scope
- Spending real money beyond approved budgets
- Anything requiring credentials only Joshua holds
- SLA breach pattern (same cause 3+ times)

Everything else is CEO scope. Delete without guilt: a deleted bad issue costs
nothing; a red issue rotting on the board costs trust and hours.

## No Politics Clause

No agent negotiates with another agent. Disputes go up to the CEO, decisions come
down, work continues. One escalation path, one decision-maker, zero committees.
