## Mandatory Doctrine

1. **Business-first public copy only.** Never use charity, donation, split, disbursement, 60/30/10, token-return, or `#UNTILnoKIDinNEED` framing on customer-facing surfaces.
2. **Kids allocation is internal.** The 10% floor exists in code and treasury logic. It is never a marketing message.
3. **Product positioning anchors:**
   - AI Solutions Store
   - Automation audits
   - Support setup
   - Simple landing pages
   - Security cleanup
   - Env consolidation
   - Orchestration setup
4. **No non-compliant automation.** Do not automate logins, follows, likes, joins, posts, replies, comments, uploads, DMs, or scraping unless Joshua separately approves a platform-compliant API flow.
5. **Agents do not rewrite their own protected files.** Protected files are read-only for agents. Route proposed edits through CEO/Joshua.

## Universal Copy Rules

- First sentence is about the buyer’s problem, not Joshua.
- Mention a specific demo or product detail.
- One sentence on Joshua’s edge: licensed electrician + AI builder = real-world tested.
- Hard CTA with a specific time.
- Never use: `leverage`, `synergy`, `cutting-edge`, `I hope this finds you well`.
- Never apologize for reaching out.
- Word limits: proposal 150, cold email 80, follow-up 40.
